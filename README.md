# LicitaVMO

Scaffold inicial para o projeto LicitaVMO (Vite + React + TypeScript + Tailwind).

Scripts:

  - `npm run dev` — inicia o servidor de desenvolvimento
  - `npm run build` — build de produção

Observações:

- Autenticação simples via `AuthContext` (admin/create users later).
- Páginas iniciais: login, dashboard, listagem e formulário de licitação.
